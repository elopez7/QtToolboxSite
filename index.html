A Toolbox Built with Qt

A collection of useful utilities written in C++ and QML. Built as a learning project to sharpen Qt skills — now running in your browser via WebAssembly.

What's Inside

🏠

All Your Tools in One Place

A clean dashboard with quick access to every utility. Navigate between tools using the sidebar — no clutter, just the tools you need.

📢

FizzBuzz

Generate the classic FizzBuzz sequence with customizable multiples. See color-coded results and live statistics for Fizz, Buzz, and FizzBuzz counts.

🔒

Password Generator

Create secure passwords with adjustable length and character types. Toggle uppercase, lowercase, numbers, and symbols with a real-time strength indicator.

💰

Loan Calculator

Calculate monthly payments with an interactive donut chart breakdown. Adjust loan amount, term, and interest rate to see principal vs. interest at a glance.
